┌─────────────────────────────────────────────────────────────────────────────┐
│ What is Training?                                                           │
├─────────────────────────────────────────────────────────────────────────────┤
│ Training = Teaching the model to recognize patterns                         │
│                                                                             │
│ 1. Show model examples: "This is normal traffic"                            │
│ 2. Show model examples: "This is a DoS attack"                              │
│ 3. Model learns patterns that distinguish them                              │
│ 4. Model can now classify new, unseen traffic                               │
│                                                                             │
│ Like teaching a child to recognize animals:                                 │
│ • Show pictures of cats → Child learns cat features                         │
│ • Show pictures of dogs → Child learns dog features                         │
│ • Child can now identify new cats and dogs                                  │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ Why 4 Different Models?                                                     │
├─────────────────────────────────────────────────────────────────────────────┤
│ Each model learns differently:                                              │
│                                                                             │
│ Random Forest: "Let's vote on it"                                           │
│ • Creates 200 decision trees                                                │
│ • Each tree votes on the answer                                             │
│ • Majority wins                                                             │
│                                                                             │
│ XGBoost: "Learn from mistakes"                                              │
│ • Builds trees sequentially                                                 │
│ • Each tree fixes errors from previous trees                                │
│ • Gradually improves accuracy                                               │
│                                                                             │
│ SVM: "Find the best boundary"                                               │
│ • Draws line separating classes                                             │
│ • Maximizes distance to nearest points                                      │
│ • Works in high-dimensional space                                           │
│                                                                             │
│ Neural Network: "Mimic the brain"                                           │
│ • Layers of artificial neurons                                              │
│ • Each neuron learns a pattern                                              │
│ • Combines patterns for final decision                                      │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ What are Features?                                                          │
├─────────────────────────────────────────────────────────────────────────────┤
│ Features = Characteristics used to identify attacks                         │
│                                                                             │
│ Network Traffic Features (41 total):                                        │
│ • duration: How long the connection lasted                                  │
│ • protocol_type: TCP, UDP, or ICMP                                          │
│ • service: HTTP, FTP, SMTP, etc.                                            │
│ • src_bytes: Bytes sent from source                                         │
│ • dst_bytes: Bytes sent to destination                                      │
│ • count: Connections to same host                                           │
│ • srv_count: Connections to same service                                    │
│ • error rates: Connection error percentages                                 │
│ • ... and 33 more                                                           │
│                                                                             │
│ Like identifying a person:                                                  │
│ • Height, weight, hair color, eye color = features                          │
│ • Model uses features to identify attack type                               │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ What is Accuracy?                                                           │
├─────────────────────────────────────────────────────────────────────────────┤
│ Accuracy = Percentage of correct predictions                                │
│                                                                             │
│ Example:                                                                    │
│ • Test on 22,544 samples                                                    │
│ • Model correctly predicts 22,250                                           │
│ • Accuracy = 22,250 / 22,544 = 98.7%                                        │
│                                                                             │
│ Higher accuracy = Better model                                              │
│ Target: ≥ 95% accuracy                                                      │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ What is Latency?                                                            │
├─────────────────────────────────────────────────────────────────────────────┤
│ Latency = Time to make one prediction                                       │
│                                                                             │
│ Example:                                                                    │
│ • Predict 22,544 samples in 0.25 seconds                                    │
│ • Latency = 0.25 / 22,544 = 0.011 milliseconds                              │
│                                                                             │
│ Lower latency = Faster detection                                            │
│ Target: < 50ms per prediction                                               │
│                                                                             │
│ Real-time detection requires low latency!                                   │
└─────────────────────────────────────────────────────────────────────────────┘
